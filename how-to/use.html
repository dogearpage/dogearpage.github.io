How to use

Replace the starter links with your own, right in the browser. No account, no install.

Where your links live: everything you add is saved in this browser on this device (its local storage). Nothing is sent to a server, and nobody else who visits the site sees your links. That also means a different browser, a different computer or clearing your browsing data starts you from the starter set again, so use Export to keep a backup.

1. Turn on Edit mode

Open the Bookmarks page and click Edit at the bottom of the page. Edit buttons appear on every category and link. Click Edit again when you're done; the page always reopens in the clean reading view.

2. Set up your categories

The page starts with three categories (Email, Social, Shopping). Keep, change or delete them.

  • Add one: click the Add Category tile at the end of the list.
  • Change one: click the pencil on its header to rename it or change its icon, emoji or color.
  • Reorder: use the up and down arrows on the header.
  • Delete: click the trash can . This removes the category and every link in it.

When adding a category you choose its Type:

TypeHoldsGood for
LinksBookmarks that open a web pageSites you visit often
Quick CopyA label and a value with a Copy buttonText you paste a lot: an address, an account number, a canned reply

The type can't be changed after the category is created, so pick the one you need up front.

For the icon, pick one from the grid or type any icon name from phosphoricons.com (for example airplane). The emoji and color fields are used by the icon styles in Settings.

3. Add your links

  1. Click the plus on the header of the category you want.
  2. Fill in Name and URL (include the https://).
  3. Optionally add a Description. You can put links inside it with [label](https://url), for example Team wiki, see also [the FAQ](https://example.com/faq).
  4. Tick Open in new tab if you want the link to leave this page open.
  5. Click Save.

To change a link, click its pencil ; you can also move it to a different category from the Category dropdown there. Click the trash can to delete it. While Edit mode is on you can also drag a link to reorder it, or drop it onto another Links category to move it there.

Quick Copy categories work the same way, except each row has a Label and a Value. Click the value or its Copy button to copy it.

4. Find things fast

Type in the search box at the top of the Bookmarks page to filter your links as you type.

5. Back up, move or share your links

Open Settings (bottom of the Bookmarks page) and use the Backup section:

  • Export JSON downloads all your categories, links and settings as a file named like newmarks-backup-2026-11-19.json.
  • Import JSON loads such a file. Use it to restore a backup, or to bring your links to another browser or computer. Importing replaces the bookmarks you have now (it doesn't add to them), so export first if you want to keep them.

Start over: Reset to defaults in Settings replaces all your bookmarks with the starter set. Export first if there's anything you want to keep.

6. The Acronyms page

The Acronyms page is a separate list for the jargon in your life. Type an acronym, its definition and an optional category, then click Add. Search, sort by any column, edit or delete entries, and use Export / Import to back the list up. Unlike bookmarks, importing acronyms adds to your list and skips any acronym you already have. The list is stored separately from your bookmarks, so resetting one never touches the other.

7. Optional: your own copy of the site

Everything above works on dogearpage.github.io as is. If you'd rather have your own address, or want your links to be the starter set anyone sees on first visit, make your own copy:

  1. Sign in to GitHub and open the repository.
  2. Click Fork to copy it to your account.
  3. In your fork, open index.html, click the pencil to edit it, and find DEFAULT_DATA. Replace the starter categories and links with yours, following the same pattern: 
    {
    name: 'News', icon: 'newspaper', emoji: '📰', color: '#1C7ED6', type: 'links', open: true, items: [
        { name: 'AP News', url: 'https://apnews.com/', desc: 'Wire service.', newTab: true }
    ]
},
    Commit the change.
  4. In your fork go to Settings → Pages, set Source to Deploy from a branch, pick main and / (root), and save. After a minute or two your copy is live at https://YOUR-USERNAME.github.io/dogearpage.github.io/. (Rename the fork to YOUR-USERNAME.github.io if you want it at the shorter address.)
The starter set is only used the first time a browser opens the page (or after Reset to defaults). A browser that already has saved links keeps them, so to see your new defaults in your own browser, export a backup and then click Reset to defaults.
